# 个性化功能快速启动指南

## 🚀 快速开始

### 第一步：打开个人设置
1. 访问 AI 论文每日速览主页
2. 点击页面顶部的"个人设置"按钮（齿轮图标）
3. 配置您的基础偏好：
   - 选择主题模式（浅色/深色/跟随系统）
   - 设置默认视图（详细/紧凑）
   - 配置阅读目标

### 第二步：开始使用个性化功能
1. **论文标注**：
   - 为感兴趣的论文添加⭐评分
   - 添加🏷️个人标签进行分类
   - 记录📝个人笔记和想法

2. **智能推荐**：
   - 阅读几篇论文后，系统会自动生成推荐
   - 点击"智能推荐"按钮查看个性化内容
   - 推荐会根据您的阅读行为持续优化

### 第三步：数据管理
1. 定期备份您的数据：
   - 点击"数据管理"按钮
   - 选择"立即备份"或启用自动备份
   - 支持多种格式导出（JSON、CSV、BibTeX、Markdown）

## 🎯 核心功能速览

### 个人标注系统
- **标签管理**：为论文添加自定义标签，建立个人分类体系
- **评分系统**：5星评分，记录论文质量和重要性
- **笔记功能**：记录阅读心得和重要观点

### 智能推荐
- **行为分析**：基于阅读时长、交互频次智能分析偏好
- **内容关联**：根据分类和关键词推荐相关论文
- **实时更新**：推荐列表随着阅读行为动态调整

### 阅读追踪
- **连续阅读**：追踪每日阅读习惯，建立学习连续性
- **统计分析**：查看阅读数量、时长、偏好分类等统计信息
- **目标设置**：设定每日/每周阅读目标，培养良好习惯

### 数据同步
- **完整备份**：一键导出所有个人数据
- **选择导入**：支持部分数据的选择性导入
- **格式兼容**：支持多种学术常用格式

## ⌨️ 快捷键

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + K` | 聚焦搜索框 |
| `Ctrl/Cmd + Shift + S` | 打开个人设置 |
| `Ctrl/Cmd + Shift + D` | 打开数据管理 |
| `Ctrl/Cmd + Shift + R` | 显示智能推荐 |
| `F` | 快速搜索收藏夹 |

## 💡 使用技巧

### 提高推荐准确性
1. **多样化阅读**：阅读不同分类的论文
2. **主动标注**：为重要论文添加标签和评分
3. **完整阅读**：花足够时间深度阅读感兴趣的论文

### 高效数据管理
1. **定期备份**：建议每周备份一次个人数据
2. **标签规范**：建立一套个人的标签命名规范
3. **笔记整理**：定期整理和回顾个人笔记

### 个性化搜索
1. **自定义分类**：创建基于个人研究方向的分类
2. **标签搜索**：使用个人标签快速定位相关论文
3. **收藏管理**：将重要论文加入收藏夹便于后续查阅

## 🔧 故障排除

### 数据丢失
- 检查浏览器是否清除了本地存储
- 尝试从最近的备份文件恢复数据
- 确保有足够的本地存储空间

### 推荐不准确
- 增加阅读样本数量（建议至少10篇）
- 检查标注数据是否反映真实偏好
- 清除旧的阅读记录重新建立偏好模型

### 性能问题
- 清理浏览器缓存
- 关闭不必要的浏览器标签页
- 考虑使用紧凑视图模式
