## 🎮 使用指南

### 快速开始
1. **打开系统** - 访问 `index.html`
2. **个性化设置** - 点击"个人设置"配置偏好
3. **开始阅读** - 浏览论文，系统会自动学习您的偏好
4. **查看推荐** - 系统会根据您的行为推荐相关论文

### 高级功能
- 使用 `Ctrl+Shift+D` 打开系统仪表板
- 使用 `Ctrl+Shift+P` 查看性能监控
- 使用 `Ctrl+Shift+R` 查看智能推荐
- 使用 `Ctrl+Shift+C` 清除缓存

### 测试验证
- 打开 `system-validation.html` 进行功能测试
- 查看 `personalization-test.html` 测试个性化功能
- 参考 `QUICK_START_GUIDE.md` 快速上手
